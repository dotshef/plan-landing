## 기능

- 관리자 관리 페이지에서 관리자 초대 및 삭제 가능
    - 관리자 초대 시 이메일을 입력하고 임시 비밀번호가 발급됨
    - 초대 받은 사람이 초대 이메일에 있는 초대 링크 클릭 시 로그인 페이지로 이동
    - 최초 로그인한 사람은 비밀번호 재설정 페이지에 진입
    - 관리자 관리페이지에서 특정 관리자 임시 비밀번호 재발급 가능
- 추천주 7일 체험 관련 기능
    - Supabase Storage 활용
    - 문자 캡처 이미지, 차트 이미지, 참여자 후기(max 3개) 등록, 수정, 삭제
- 4분기 섹터 관련 기능
    - 코스피 평균 PER 수정 기능
    - N년도 N분기 수정 가능 (각각 정수형으로 입력)
    - 섹터 지정 기능
        - 섹터의 ‘이름’, ‘주제’ 추가, 삭제
    - 섹터 별 종목 지정 기능
        - 종목 코드, 종목명 검색 지원 (기존 검색 기능 재활용)
        - 섹터에 등록 및 제외 기능
    - 각 섹터에 종목이 등록이 되고 나면 다음을 확인
        - N분기 영업이익, PER, N-1분기 영업이익, PER
            - 만약 특정 종목의 N분기 영업이익 또는 N-1분기 영업이익이 존재하지 않는다면 관리자 사이트 UI로 빨간 표시로 “N분기 영업이익이 제공되지 않았습니다.” 또는 “N-1분기 영업이익이 제공되지 않았습니다.” 혹은 둘 다 표시. 이 경우 “사이트 배포 버튼은 비활성화 처리. 계산이 불가하도록 서버에서 처리
        - N분기, N-1분기에 해당하는 거래대금, 외국인 순매수 데이터를 확인
            - 거래대금은 `price_daily.trading_value`, 외국인 순매수는 `investor_trend_daily.foreign_net` 에 존재
            - 해당 분기의 특정 날짜 데이터가 존재하지 않을 경우 “N분기 거래대금 데이터가 불완전합니다” 로 빨간색 표시. 사이트 배포 버튼 비활성화. 계산 불가.
    - 모든 종목의 데이터가 제공 가능 상태일 때 가장 하단 사이트 배포 버튼을 누르면 각 섹터 별로 다음을 계산하여 DB 저장. 모든 계산 값은 단순 산술 평균으로 구함
        - 영업이익 증가율
        - 업종 PER
        - 거래대금 증가율
        - 외국인 순매수
    - 4분기 섹터 페이지에서 섹터별로 등록된 종목 코드를 기반으로 최신 뉴스 최대 5개를 가져와서 렌더링 (news 테이블)
